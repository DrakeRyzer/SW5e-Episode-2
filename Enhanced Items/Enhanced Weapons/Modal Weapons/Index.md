# Modal Weapons
```(formally modal exotic weapons)```

Modal Weapons have the capacity to switch between two or more weapons at will; such as a vibrostaff that can switch to a blaster rifle or a blaster rifle with a built in grenade launcher or sniper rifle.

### DC-17m Interchangeable Weapon System
*Weapon [(heavy carbine, sniper rifle, grenade launcher)](https://sw5e.com/loot/weapons/?search=Heavy%20carbine), <font style="color:lime">premium</font>*
10lb

*A type of reconfigurable repeating blaster rifle used by Republic clone commandos during the Clone Wars and the early days of the Empire.*

This weapon comes with three modes based on weapons: a heavy carbine, a sniper rifle and a grenade launcher and you track the reload value for each mode separately. Only one mode can be active at a time. You can change which mode is active as an Object Interaction.
